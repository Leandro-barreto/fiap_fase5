# 📊 data/ – Conjuntos de Dados

Esta pasta armazena os datasets utilizados no projeto.  Por motivos de espaço e privacidade, os dados brutos não são versionados no repositório e devem ser baixados separadamente.

## 📂 Estrutura sugerida

- **`external/`** – dados externos fornecidos originalmente (por exemplo, `synthetic_batch_input.csv`).
- **`processed/`** – dados tratados e prontos para consumo.
- **`interim/`** – artefatos intermediários gerados durante o pré-processamento.

## 📁 Obtendo os dados

Os datasets brutos estão hospedados em um Google Drive compartilhado:  
https://drive.google.com/drive/folders/1f3jtTRyOK-PBvND3JTPTAxHpnSrH7rFR

Após o download, colocar os arquivos em  `external/`.
Os demais arquivos são criados pelo pipeline, ou já estão no repositório do github.
